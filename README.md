# Sriram Gopalakrishnan, Ph.D. — Personal Website

This repository contains the source code for the personal academic and research portfolio website of **Sriram Gopalakrishnan, Ph.D.** (AI Research Lead at J.P. Morgan Chase).

## Research Focus
- **Sequential Decision Making**: Automated Planning, MDPs, Reinforcement Learning, and Makespan Scheduling under Uncertainty.
- **Human-AI Interaction & Teaming**: Cognitive Modeling, State Aliasing, Explainable AI (XAI), and Risk-Aware Algorithmic Recourse (SafeAR).
- **Hybrid-Agent Systems (Generative + Classical AI)**: Combining Large Language Models (LLMs) and diffusion models with symbolic automated planners and formal constraint solvers (TRIP-PAL, GenPlanX, synthetic multi-hop reasoning data generation).

## Site Structure
- `_pages/`: Main website pages (`about.md`, `publications.md`, `resume.md`, `portfolio.html`, `talks.html`).
- `_publications/`: Peer-reviewed conference papers, journal articles, and workshop publications.
- `_portfolio/`: Hallmark research systems, production deployments, patents, and open-source tools.
- `_talks/`: Keynotes, conference oral presentations, invited panels, and dissertation defenses.
- `_sass/_custom.scss`: Modern responsive design system, award badges, and interactive components.
- `files/`: Curriculum Vitae (PDF) and downloadable assets.
